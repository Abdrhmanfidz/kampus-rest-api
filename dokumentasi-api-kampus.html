GET — Lihat Semua Data

// Mengambil seluruh data dari database

GET /api.php?table=matkul Semua mata kuliah ▼
1

Buka Postman, buat Request baru

Klik tombol + New → pilih HTTP Request

2

Set Method ke GET

Pastikan dropdown method di sebelah kiri URL sudah terpilih GET

3

Masukkan URL berikut

URL 
https://kampus-rest-api-production.up.railway.app/api.php?table=matkul
4

Klik tombol Send

Lihat response di bagian bawah Postman

Contoh Response

JSON 
{
  "status": "success",
  "data": [
    {
      "id_matkul": 1,
      "nama_matkul": "Pemrograman Web",
      "sks": 3,
      "id_mahasiswa": 1,
      "id_dosen": 1
    }
  ]
}
✅
Gunakan /api.php tanpa parameter untuk menampilkan semua tabel sekaligus (mahasiswa, dosen, dan mata kuliah).
GET /api.php?table=matkul-detail Matkul + JOIN ▼
1

Masukkan URL berikut di Postman

URL 
https://kampus-rest-api-production.up.railway.app/api.php?table=matkul-detail
2

Klik Send

Response akan menampilkan mata kuliah beserta nama mahasiswa dan nama dosen yang terkait.

Contoh Response

JSON
{
  "status": "success",
  "data": [
    {
      "id_matkul": 1,
      "nama_matkul": "Pemrograman Web",
      "sks": 3,
      "nama_mahasiswa": "Budi Santoso",
      "nama_dosen": "Dr. Hendra"
    }
  ]
}
🔍

GET — Lihat Data by ID

// Mengambil satu data berdasarkan ID

GET /api.php?table=matkul&id=1 Matkul by ID ▼
1

Masukkan URL dengan parameter id

URL 
https://kampus-rest-api-production.up.railway.app/api.php?table=matkul&id=1
2

Ganti angka 1 dengan ID yang ingin dicari

Contoh: ?table=matkul&id=2 untuk data dengan id_matkul = 2

3

Klik Send

Contoh Response

JSON
{
  "status": "success",
  "data": {
    "id_matkul": 1,
    "nama_matkul": "Pemrograman Web",
    "sks": 3,
    "id_mahasiswa": 1,
    "id_dosen": 1
  }
}
⚠️
Jika ID tidak ditemukan, response akan mengembalikan "Data tidak ditemukan" dengan status "error".
➕

POST — Tambah Data

// Menambahkan data baru ke database

POST /api.php?table=matkul Tambah mata kuliah ▼
1

Set Method ke POST dan masukkan URL

URL 
https://kampus-rest-api-production.up.railway.app/api.php?table=matkul
2

Klik tab Headers → tambahkan:

Headers
Content-Type  :  application/json
3

Klik tab Body → pilih raw → pilih JSON

4

Masukkan data JSON berikut

JSON Body 
{
  "nama_matkul": "Pemrograman Web",
  "sks": 3,
  "id_mahasiswa": 1,
  "id_dosen": 1
}
5

Klik Send

Contoh Response Berhasil

JSON
{
  "status": "success",
  "message": "Mata kuliah berhasil ditambahkan"
}
💡
id_mahasiswa dan id_dosen harus menggunakan ID yang sudah ada di tabel mahasiswa dan dosen.
✏️

PUT — Update Data

// Mengubah data yang sudah ada

PUT /api.php?table=matkul&id=1 Update mata kuliah ▼
1

Set Method ke PUT dan masukkan URL

URL 
https://kampus-rest-api-production.up.railway.app/api.php?table=matkul&id=1

Ganti id=1 dengan ID data yang ingin diupdate

2

Tambahkan Header Content-Type: application/json

3

Klik tab Body → raw → JSON, isi dengan data baru

JSON Body 
{
  "nama_matkul": "Basis Data Lanjut",
  "sks": 4,
  "id_mahasiswa": 2,
  "id_dosen": 2
}
4

Klik Send

Contoh Response Berhasil

JSON
{
  "status": "success",
  "message": "Mata kuliah berhasil diupdate"
}
⚠️
Semua field harus diisi saat PUT. Jika ada field yang kosong, data tersebut akan diupdate menjadi kosong.
🗑️

DELETE — Hapus Data

// Menghapus data dari database

DELETE /api.php?table=matkul&id=1 Hapus mata kuliah ▼
1

Set Method ke DELETE dan masukkan URL

URL 
https://kampus-rest-api-production.up.railway.app/api.php?table=matkul&id=1

Ganti id=1 dengan ID data yang ingin dihapus

2

Klik Send — tidak perlu Body

DELETE tidak memerlukan Body JSON, cukup URL saja.

Contoh Response Berhasil

JSON
{
  "status": "success",
  "message": "Mata kuliah berhasil dihapus"
}
⚠️
Hati-hati! Data yang sudah dihapus tidak bisa dikembalikan. Pastikan ID yang dimasukkan sudah benar sebelum klik Send.
👨‍🎓
